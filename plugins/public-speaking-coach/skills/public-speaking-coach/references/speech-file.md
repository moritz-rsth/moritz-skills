# Speech File

This is the user's personal, growing bank of quotes, facts, and stories worth reusing across speeches — the "speech file" concept from the Romancing the Room material (build a repository from family, work, school, and stories heard from others). Check this file in Step 0 of every drafting task before inventing new material from scratch, and only use an entry where it's genuinely apt for the audience (the ABC rule in `openers-and-structure.md`) — a forced quote is worse than none.

**Keep this file growing.** When the user mentions a quote, statistic, or story mid-conversation that isn't logged here and looks reusable beyond the speech at hand, offer to add it using the format below. See Step 0 in SKILL.md for what to do if this file turns out to be read-only in a given session.

## Entry format

When adding a new entry, use one of these three shapes so entries stay scannable:

```
### [Quote / Fact / Story] — <short title>
"<the quote, fact, or a one-line story summary>"
— <source, if any>
Good for: <what kind of point/occasion this supports>
```

## Worked examples (the user's own speeches — use as a quality/tone bar, not to copy verbatim)

### "Audience Before Content" — dessert toast, 08/12/2025
One of the user's strongest toasts to date. What makes it work, worth reusing as technique:
- Opens by toasting an idea ("three simple words") rather than a person — a Grabber-style hook that's unusual for a toast.
- Uses a rhetorical question sequence ("But why is it so important?") followed by a deliberately blunt, funny answer ("I have no clue // :)") before pivoting to the real answer — classic curiosity arousal into payoff.
- Grounds the abstract concept (audience before content) in one specific personal detail (starting to study math in 10th grade) rather than staying theoretical.
- Uses the Maya Angelou quote above as the emotional turn before the close.
- Capsule close: repeats "Audience Before Content" / "ABC" from the opener, so the toast visibly completes its own loop.

### "Stand up for your future" — sales speech, 08/02/2025
A persuasive/sales speech worth reusing as technique reference for business pitches:
- Opens with a Problem-to-Solve hook grounded in a relatable physical sensation ("It's 5 PM. Your shoulders ache...") rather than starting with the product.
- Uses the escalating time-scale progression device ("In seconds... In minutes... In days... In years...") — see `openers-and-structure.md` for the general version of this technique.
- Names a likely objection directly before answering it ("Some of you might think, 'Won't standing all day make me even more tired?' — but...") — see the objection-preempt technique in `openers-and-structure.md`.
- Backs the pitch with concrete stats (80% of adults, $50-100 per session, 2,000 hours annually) rather than vague claims — logos doing real work.
- Ends with a specific, low-friction call to action (scan the QR code) and a callback to the title line as the final beat.
